# Heizung PR 18: §§ 5a, 5b, 5d CO2KostAufG ab 2028 (#215) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bei einer Gas-, Öl- oder Flüssiggasheizung nach § 43 Abs. 1 GModG trägt der Vermieter ab dem
01.01.2028 die Hälfte der Gasnetzentgelte und der CO₂-Kosten und ab dem 01.01.2029 die Hälfte der Kosten des
Pflichtanteils an Biobrennstoff (§ 5a CO2KostAufG), entsprechend in Neubauten nach § 5b, außer im selbst
bewohnten Zweifamilienhaus außerhalb angespannter Wohnungsmärkte (§ 5d Abs. 3); Mietfuchs rechnet das je
Heizperiode anteilig nach Anfall, bucht die Anteile als Abzugszeilen, prüft die Angaben des Messdienstes und
nennt Notfalleinbau (§ 5a Abs. 4), Härtefall (§ 5d Abs. 1) und Mitteilungspflicht (§ 5d Abs. 4).

**Architecture:** Das Rechtsregister bekommt die Zeitregel `incurred` (`law()` liefert Segmente mit Gewicht)
und fünf Parameter (`co2.half-split` mit drei Fassungen, `.new-buildings`, `.emergency`, `.two-family`,
`gmodg.heating-43`). Die Merkmale stehen an der Heizanlage (sechs Spalten) und am Objekt (`tight_market`), in
zwei erzeugten Schritten `0040`/`0041`; Netzentgelte und Biobrennstoff an der Lieferung gibt es seit PR 7 und
werden hier freigegeben. Die Entscheidung, wo im Zeitraum § 5a greift, steht als reine Funktionen in
`server/src/halfSplit.ts`; `computeSettlement` mischt damit im CO₂-Block den Anteil des Vermieters an den
CO₂-Kosten (`selfSplit`, Nachstufung, Etagenheizung) und bucht Netzentgelte und Biobrennstoff als eigene
Abzugszeilen (`gmodgRelief`, beim Vermieter `gmodgShare`, § 7 Abs. 5). Die Oberfläche bekommt auf der Seite
Heizkosten die Karte „Heizung nach § 43 GModG“, an der Lieferung zwei Beträge und am Objekt die Frage zum
angespannten Wohnungsmarkt.

**Tech Stack:** Node 24 (TypeScript ohne Build, Typen werden abgestreift), Express 5, Drizzle ORM 0.45 über
`sqlite-proxy`, drizzle-kit 0.31, `node:test`, React 19 + Vite, vitest mit jsdom.

## Review Focus

1. **Eine Heizperiode Mai 2027 bis April 2028 bei einer Anlage, die am 15.06.2027 nach irreparablem Ausfall
   eingebaut wurde** (§ 5a Abs. 4 Satz 1). Erwartet: Bis einschließlich 15.06.2028 keine hälftige Teilung
   (zwölf Monate ab dem Einbau, §§ 187 Abs. 1, 188 Abs. 2 BGB), also in dieser Heizperiode gar keine, und
   der Hinweis nennt den Grund. Test in Task 4.
2. **Ein Zweifamilienhaus mit Eigennutzung, Mitteilung nach § 5d Abs. 4 erst am 15.03.2028, Heizperiode
   Kalenderjahr 2028.** Erwartet: Die Mitteilung kam nach Beginn des Zeitraums und wird in ihm nicht
   berücksichtigt (Abs. 4 Satz 4); 2028 wird hälftig geteilt, 2029 nach Stufen, und der Hinweis sagt beides.
   Test in Task 4 und Task 5.
3. **Eine Gasrechnung 15.10.2027–14.10.2028 mit einer Zwischenrechnung zum 31.12.2027.** Erwartet: Die
   Netzentgelte der Zwischenrechnung bleiben ganz beim Mieter, die der Schlussrechnung werden hälftig
   geteilt, soweit ihr Zeitraum in die Heizperiode fällt; Gradtage entscheiden nur dort, wo keine Rechnung
   abgegrenzt ist. Test in Task 6.
4. **Eine Ölheizung nach § 43 Abs. 1 ab 2029.** Den Biobrennstoff aus dem Tank (Vorrat) rechnet dieser PR
   nicht. Erwartet: keine stille Null, sondern `co2.half-split-missing` mit 3 % je Mieter und dem Satz, dass
   Mietfuchs das mit einer späteren Version rechnet; die Eingabe eines Biobetrags an einer Öllieferung
   antwortet mit 400 und einem Satz. Tests in Task 3 und Task 6.
5. **Der Messdienst rechnet ab 2028 mit 50 % für die ganze Heizperiode statt anteilig.** Erwartet: die
   Nachstufung meldet `co2.stage-mismatch` (hint), nennt den erwarteten Anteil nach Anfall und bucht nichts
   um; die Probe der Beträge bleibt davon unberührt. Test in Task 5.

```ts
// Tage eines Bereichs, beide Grenzen eingeschlossen, in UTC.
export function daysIn(range: Period): number {
  const at = (iso: string): number => {
    const [y, m, d] = iso.split('-').map(Number)
    return Date.UTC(y ?? 0, (m ?? 1) - 1, d ?? 1)
  }
  return Math.round((at(range.to) - at(range.from)) / 86400000) + 1
}

// Derselbe Tag `months` Monate später (oder früher); fehlt er im Zielmonat, dessen letzter Tag.
export function shiftMonths(iso: string, months: number): string {
  const [y, m, d] = iso.split('-').map(Number)
  const total = (y ?? 0) * 12 + ((m ?? 1) - 1) + months
  const ty = Math.floor(total / 12)
  const tm = total - ty * 12 + 1
  const last = new Date(Date.UTC(ty, tm, 0)).getUTCDate()
  return `${String(ty).padStart(4, '0')}-${String(tm).padStart(2, '0')}-${String(Math.min(d ?? 1, last)).padStart(2, '0')}`
}

// Das Ende eines Zeitraums von `months` Monaten ab einem Ereignis (Einbau, Abrechnung, Anzeige): Der Tag
// des Ereignisses zählt nicht mit (§ 187 Abs. 1 BGB), der Zeitraum endet mit Ablauf des Tages, der ihm
// durch seine Zahl entspricht (§ 188 Abs. 2 BGB), fehlt er, mit dem Monatsletzten (§ 188 Abs. 3 BGB).
// § 186 BGB erstreckt das auf Fristen in Gesetzen.
export const eventPeriodEnd = (eventIso: string, months: number): string => shiftMonths(eventIso, months)
```

Hinter `OverlapAnswer`:

```ts
// Ein Teil eines Zeitraums mit der Fassung, die darin gilt, und seinem Gewicht am Ganzen (Summe 1).
export type IncurredSegment<T extends LawValue> = { from: string; to: string; value: T; weight: number }

// Die Fassungen eines Parameters, auf einen Bereich zugeschnitten, ohne Protokoll. Für Rechnungen, die
// innerhalb eines Zeitraums nach Teilen fragen (§ 5a je Lieferung); was davon angewandt wird, protokolliert
// `law()` mit `incurred` für den Zeitraum der Abrechnung.
export function versionsIn<T extends LawValue>(param: LawParam<T>, range: Period): { from: string; to: string; value: T }[] {
  versionAt(param, range.from)
  versionAt(param, range.to)
  return param.versions
    .filter((v) => (v.validFrom === undefined || v.validFrom <= range.to) && (v.validTo === undefined || v.validTo >= range.from))
    .map((v) => ({
      from: v.validFrom !== undefined && v.validFrom > range.from ? v.validFrom : range.from,
      to: v.validTo !== undefined && v.validTo < range.to ? v.validTo : range.to,
      value: v.value,
    }))
}
```

Die Überladungen von `law()` (Stand PR 17) ersetzen durch:

```ts
export function law<T extends LawValue>(param: LawParam<T, 'periodStart'>, ctx: { period: Period }, log: LawLog): T
export function law<T extends LawValue>(param: LawParam<T, 'eventDate'>, ctx: { date: string }, log: LawLog): T
export function law<T extends LawValue>(param: LawParam<T, 'deliveryYear'>, ctx: { year: number }, log: LawLog): T
export function law<T extends LawValue>(param: LawParam<T, 'overlap'>, ctx: { period: Period }, log: LawLog): OverlapAnswer<T>
export function law<T extends LawValue>(param: LawParam<T, 'incurred'>, ctx: { period: Period; weights: (range: Period) => number }, log: LawLog): IncurredSegment<T>[]
export function law<T extends LawValue>(
  param: LawParam<T, Timing>,
  ctx: { period: Period } | { date: string } | { year: number } | { period: Period; weights: (range: Period) => number },
  log: LawLog,
): T | OverlapAnswer<T> | IncurredSegment<T>[] {
  // Ein Wert, den der Vermieter eintragen darf, geht über lawOverridable (PR 17, Abweichung 1).
  if (param.overridable) throw new Error(`Rechtswert „${param.id}“ ist überschreibbar; bitte lawOverridable nehmen`)
  if (param.timing === 'incurred' && 'weights' in ctx) return incurred(param, ctx.period, ctx.weights, log)
  if (param.timing === 'overlap' && 'period' in ctx) return overlap(param, ctx.period, log)
  const date = 'period' in ctx ? ctx.period.from : 'year' in ctx ? yearStart(ctx.year) : ctx.date
  const version = versionAt(param, date)
  record(log, param, version)
  return version.value
}

// `incurred` (Heizung PR 18, Entwurf 4.2): der Zeitraum, geteilt an den Grenzen der Fassungen, jeder Teil mit
// seinem Gewicht. Die Gewichte misst der Aufrufer (`weights`) und `law()` normiert sie auf die Summe 1. Misst
// er nirgends etwas, gelten die Tage, damit kein Teil verschwindet. Protokolliert wird jede Fassung mit
// Gewicht; eine ohne Gewicht ist im Zeitraum nicht angewandt (wie `none` bei `overlap`).
function incurred<T extends LawValue>(param: LawParam<T>, period: Period, weights: (range: Period) => number, log: LawLog): IncurredSegment<T>[] {
  const parts = versionsIn(param, period)
  const measured = parts.map((p) => Math.max(0, weights({ from: p.from, to: p.to })))
  const byDays = measured.reduce((a, w) => a + w, 0) <= 0
  const w = byDays ? parts.map((p) => daysIn(p)) : measured
  const total = w.reduce((a, x) => a + x, 0)
  return parts.map((p, i) => {
    const weight = total > 0 ? (w[i] ?? 0) / total : 0
    if (weight > 0) record(log, param, versionAt(param, p.from))
    return { from: p.from, to: p.to, value: p.value, weight }
  })
}
```

```ts
// Hälftige Teilung nach §§ 5a, 5b, 5d CO2KostAufG (Heizung PR 18, #215; Entwurf 3.9, 3.13, 4.3, 15.1 Nr. 13,
// Nr. 20). Reine Funktionen. Rechtswerte reicht der Aufrufer aus dem Register herein (`law()` protokolliert
// sie); hier steht kein Datum und keine Rechtszahl (law-literals.test.ts).
import type { DayRange } from '../../shared/degreeDays.ts'
import type { HalfSplitValue } from '../../shared/law/co2kostaufg.ts'
import { dayAfter, dayBefore, eventPeriodEnd, shiftMonths } from '../../shared/law/register.ts'

export type HalfSplitFacts = {
  gmodg43InstalledOn: string | null
  emergencyInstall: boolean | null
  emergencyPriorDuty: boolean | null
  newBuildingFirstUse: string | null
  buildingApplicationBefore20260513: boolean | null
}
// Die Werte aus `co2.half-split.new-buildings` und `co2.half-split.emergency`; `null`, wenn der Aufrufer sie
// nicht braucht (kein Neubau, kein Notfalleinbau) und sie deshalb nicht abgefragt hat.
export type HalfSplitRules = {
  newBuildings: { firstUseUntil: string; applicationFrom: string } | null
  emergency: { windowMonths: number; before: string; yearFrom: string; yearTo: string; laterFrom: string } | null
}
export type HalfSplitExclusion = { from: string; to: string; rule: 'emergency1' | 'emergency2' | 'emergency3' }
// `assumed`: Eine Angabe fehlt, und Mietfuchs teilt trotzdem hälftig (Abweichungen 3, 4): der Bauantrag beim
// Neubau, die vorherige Pflicht beim Notfalleinbau ab 2028. Der Hinweis fragt danach.
export type HalfSplitStatus =
  | { kind: 'none' }
  | { kind: 'excluded'; reason: 'applicationBefore' }
  | { kind: 'applies'; basis: 'existing' | 'newBuilding'; from: string; excluded: HalfSplitExclusion[]; assumed: ('application' | 'priorDuty')[] }

// Ob und ab wann § 5a für eine Anlage greift (§ 5a Abs. 1, 4; § 5b). Die Grenze des ersten Tags (01.01.2028)
// steht nicht hier, sondern in den Fassungen von `co2.half-split`; hier nur, was an der Anlage hängt.
export function halfSplitStatus(f: HalfSplitFacts, rules: HalfSplitRules): HalfSplitStatus {
  const installed = f.gmodg43InstalledOn
  if (installed === null) return { kind: 'none' }
  const assumed: ('application' | 'priorDuty')[] = []
  let basis: 'existing' | 'newBuilding' = 'existing'
  if (f.newBuildingFirstUse !== null) {
    basis = 'newBuilding'
    // § 5b Satz 2: kein § 5a bei Bauantrag, Antrag auf Zustimmung oder Bauanzeige vor dem Stichtag.
    if (f.buildingApplicationBefore20260513 === true) return { kind: 'excluded', reason: 'applicationBefore' }
    if (f.buildingApplicationBefore20260513 === null) assumed.push('application')
  }
  const excluded: HalfSplitExclusion[] = []
  const e = rules.emergency
  if (f.emergencyInstall === true && e !== null) {
    if (installed > shiftMonths(e.before, -e.windowMonths) && installed < e.before) {
      // Satz 1: weniger als zwölf Monate vor dem ersten Tag eingebaut.
      excluded.push({ from: installed, to: eventPeriodEnd(installed, e.windowMonths), rule: 'emergency1' })
    } else if (installed >= e.yearFrom && installed <= e.yearTo) {
      // Satz 2: während des Zeitraums aus § 43 Abs. 7 Satz 1 GModG, wenn beim Ausfall keine Pflicht bestand.
      if (f.emergencyPriorDuty === false) excluded.push({ from: e.yearFrom, to: e.yearTo, rule: 'emergency2' })
      else if (f.emergencyPriorDuty === null) assumed.push('priorDuty')
    } else if (installed >= e.laterFrom) {
      // Satz 3: im Fall des § 43 Abs. 7 Satz 2 GModG zwölf Monate ab dem Einbau, unter derselben Bedingung.
      if (f.emergencyPriorDuty === false) excluded.push({ from: installed, to: eventPeriodEnd(installed, e.windowMonths), rule: 'emergency3' })
      else if (f.emergencyPriorDuty === null) assumed.push('priorDuty')
    }
  }
  return { kind: 'applies', basis, from: installed, excluded, assumed }
}

export function intersect(a: DayRange, b: DayRange): DayRange | null {
  const from = a.from > b.from ? a.from : b.from
  const to = a.to < b.to ? a.to : b.to
  return from <= to ? { from, to } : null
}

// Die Tage eines Bereichs, an denen die Anlage für § 5a in Frage kommt: ab dem Einbau, ohne die Zeiten nach
// § 5a Abs. 4. Ob eine Fassung von `co2.half-split` dort teilt, entscheiden die Teile (`Piece`).
export function applicableRanges(s: HalfSplitStatus, span: DayRange): DayRange[] {
  if (s.kind !== 'applies') return []
  const start = intersect(span, { from: s.from, to: span.to })
  if (!start) return []
  let out: DayRange[] = [start]
  for (const x of [...s.excluded].sort((a, b) => (a.from < b.from ? -1 : a.from > b.from ? 1 : 0))) {
    out = out.flatMap((r) => {
      const cut = intersect(r, x)
      if (!cut) return [r]
      const parts: DayRange[] = []
      if (r.from < cut.from) parts.push({ from: r.from, to: dayBefore(cut.from) })
      if (cut.to < r.to) parts.push({ from: dayAfter(cut.to), to: r.to })
      return parts
    })
  }
  return out
}

export type TwoFamilyFacts = { dwellings: number; selfUsed: boolean; central: boolean; servesAll: boolean; tightMarket: boolean | null; noticeOn: string | null }
export type TwoFamily =
  | { kind: 'notApplicable' }
  | { kind: 'excepted'; noticeOn: string }
  | { kind: 'split'; reason: 'tightMarket' | 'tightMarketUnknown' | 'noNotice' | 'noticeLate'; noticeOn: string | null }

// § 5d Abs. 3, 4 (Abweichungen 3, 4, 15): Ausnahme nur bei höchstens zwei Wohnungen, einer davon selbst
// bewohnt, beide an einer zentralen Anlage; nicht im angespannten Markt; nur mit Mitteilung vor Beginn des
// Zeitraums. Fehlt eine Voraussetzung oder ist sie unbekannt, wird hälftig geteilt, und der Grund steht da.
export function twoFamilyOf(f: TwoFamilyFacts, maxDwellings: number, hFrom: string): TwoFamily {
  if (f.dwellings > maxDwellings || !f.selfUsed || !f.central || !f.servesAll) return { kind: 'notApplicable' }
  if (f.tightMarket === true) return { kind: 'split', reason: 'tightMarket', noticeOn: f.noticeOn }
  if (f.tightMarket === null) return { kind: 'split', reason: 'tightMarketUnknown', noticeOn: f.noticeOn }
  if (f.noticeOn === null) return { kind: 'split', reason: 'noNotice', noticeOn: null }
  if (f.noticeOn >= hFrom) return { kind: 'split', reason: 'noticeLate', noticeOn: f.noticeOn }
  return { kind: 'excepted', noticeOn: f.noticeOn }
}

export type Piece = { from: string; to: string; value: HalfSplitValue }
// Ein Anteil des Zeitraums, in dem der Vermieter `permille` trägt, mit seinem Gewicht am Ganzen.
export type HalfSplitTerm = { permille: number; weight: number }

// Die Teile, in denen eine Kostenart hälftig geteilt wird, gewichtet nach `weigh` (Gradtage der Heizperiode):
// für die CO₂-Kosten ohne Lieferungen (Messdienst, Vorrat; Abweichung 2).
export function termsFromPieces(pieces: readonly Piece[], applicable: readonly DayRange[], weigh: (r: DayRange) => number, pick: (v: HalfSplitValue) => number | null): HalfSplitTerm[] {
  const first = pieces[0]
  const last = pieces.at(-1)
  if (!first || !last) return []
  const total = weigh({ from: first.from, to: last.to })
  if (total <= 0) return []
  const terms: HalfSplitTerm[] = []
  for (const p of pieces) {
    const permille = pick(p.value)
    if (permille === null) continue
    for (const a of applicable) {
      const r = intersect(p, a)
      const w = r ? weigh(r) / total : 0
      if (w > 0) terms.push({ permille, weight: w })
    }
  }
  return terms
}

export type HalfDelivery = { id: string; label: string; base: DayRange | null; portion: number; co2Cents: number | null; gridFeeCents: number | null; bioCostCents: number | null }

// Der Teil einer Lieferung, der im Bereich `base` auf Tage mit hälftiger Teilung fällt, je Fassung (§ 5a
// Abs. 1 „angefallen“, umgerechnet wie Facette 2; Abweichung 2). `share(id, r)` ist der Anteil des
// verbrauchsabhängigen Teils der Lieferung an `r` nach den Stufen 1–5.
function halfFractions(d: HalfDelivery, piecesOf: (r: DayRange) => readonly Piece[], applicable: readonly DayRange[], share: (id: string, r: DayRange) => number, pick: (v: HalfSplitValue) => number | null): HalfSplitTerm[] {
  if (!d.base) return []
  const whole = share(d.id, d.base)
  if (whole <= 0) return []
  const out: HalfSplitTerm[] = []
  for (const p of piecesOf(d.base)) {
    const permille = pick(p.value)
    if (permille === null) continue
    for (const a of applicable) {
      const r = intersect(p, a)
      const w = r ? share(d.id, r) / whole : 0
      if (w > 0) out.push({ permille, weight: w })
    }
  }
  return out
}

// CO₂ nach Lieferungen: jede Lieferung mit ihren CO₂-Kosten im Zeitraum (C · Anteil) gewogen.
export function termsFromDeliveries(list: readonly HalfDelivery[], piecesOf: (r: DayRange) => readonly Piece[], applicable: readonly DayRange[], share: (id: string, r: DayRange) => number, pick: (v: HalfSplitValue) => number | null): HalfSplitTerm[] {
  const total = list.reduce((a, d) => a + (d.co2Cents ?? 0) * d.portion, 0)
  if (total <= 0) return []
  return list.flatMap((d) => halfFractions(d, piecesOf, applicable, share, pick).map((t) => ({ permille: t.permille, weight: (t.weight * (d.co2Cents ?? 0) * d.portion) / total })))
}

export const termsWeight = (terms: readonly HalfSplitTerm[]): number => terms.reduce((a, t) => a + t.weight, 0)

// Der Anteil des Vermieters an den CO₂-Kosten: außerhalb der Teile `base` (Stufe, § 8, § 9), in den Teilen
// ihr Anteil (§ 5a Abs. 3 Nr. 2). Ohne Stufe nur, wenn der ganze Zeitraum geteilt wird.
export function blendedPermille(base: number | null, terms: readonly HalfSplitTerm[]): number | null {
  const w = termsWeight(terms)
  const half = terms.reduce((a, t) => a + t.weight * t.permille, 0)
  if (base === null) return w >= 1 - 1e-9 ? half : null
  return base * (1 - w) + half
}

export type HalfAmounts = { gridFeeRaw: number; bioRaw: number; missingGrid: string[]; missingBio: string[] }

// Netzentgelte und Biobrennstoff des Vermieters (§ 5a Abs. 1, 3, § 7 Abs. 5), exakt, gerundet wird bei der
// Verteilung. `portion`: der Teil der Lieferung, der in diese Heizperiode gehört (bei freien Schlüsseln der
// abgegrenzte Anteil, beim Messdienst die ganze angesetzte Rechnung). Fehlt ein Betrag an einer Lieferung mit
// Tagen in der Teilung, steht ihr Name in `missing…` (Abweichung 9).
export function halfAmounts(list: readonly HalfDelivery[], piecesOf: (r: DayRange) => readonly Piece[], applicable: readonly DayRange[], share: (id: string, r: DayRange) => number, gas: boolean): HalfAmounts {
  const out: HalfAmounts = { gridFeeRaw: 0, bioRaw: 0, missingGrid: [], missingBio: [] }
  for (const d of list) {
    if (gas) {
      const t = halfFractions(d, piecesOf, applicable, share, (v) => v.gridFeePermille)
      if (t.length > 0) {
        if (d.gridFeeCents === null) out.missingGrid.push(d.label)
        else out.gridFeeRaw += t.reduce((a, x) => a + (d.gridFeeCents ?? 0) * d.portion * x.weight * (x.permille / 1000), 0)
      }
    }
    const b = halfFractions(d, piecesOf, applicable, share, (v) => v.bioPermille)
    if (b.length > 0) {
      if (d.bioCostCents === null) out.missingBio.push(d.label)
      else out.bioRaw += b.reduce((a, x) => a + (d.bioCostCents ?? 0) * d.portion * x.weight * (x.permille / 1000), 0)
    }
  }
  return out
}
```

```ts
// costForm.ts; die Komponente rendert nur.
import type { HeatingEnergy, HeatingPlant } from './types'
import { gmodgHeating43 } from '../../shared/law/gmodg.ts'
import { co2HalfSplitNewBuildings } from '../../shared/law/co2kostaufg.ts'
import { germanDate, LAW_AS_OF, valueAt } from '../../shared/law/register.ts'

export type TriState = 'unknown' | 'yes' | 'no'
export const TRI_OPTIONS: { value: TriState; label: string }[] = [
  { value: 'unknown', label: 'Weiß ich nicht' },
  { value: 'yes', label: 'Ja' },
  { value: 'no', label: 'Nein' },
]
export type HalfSplitBody = Pick<HeatingPlant, 'gmodg43InstalledOn' | 'emergencyInstall' | 'emergencyPriorDuty' | 'newBuildingFirstUse' | 'buildingApplicationBefore20260513' | 'halfSplitNoticeOn'>
export type HalfSplitForm = { installedOn: string; emergency: boolean; priorDuty: TriState; newBuilding: boolean; firstUse: string; applicationBefore: TriState; noticeOn: string }

const NB = valueAt(co2HalfSplitNewBuildings, LAW_AS_OF)

export const APPLICATION_FROM = germanDate(NB.applicationFrom)
export const FIRST_USE_UNTIL = germanDate(NB.firstUseUntil)

export const halfSplitAvailable = (energy: HeatingEnergy): boolean => H43.energies.includes(energy)

const tri = (v: boolean | null): TriState => (v === null ? 'unknown' : v ? 'yes' : 'no')
const fromTri = (t: TriState): boolean | null => (t === 'unknown' ? null : t === 'yes')

export function halfSplitToForm(p: HalfSplitBody): HalfSplitForm {
  return {
    installedOn: p.gmodg43InstalledOn ?? '',
    emergency: p.emergencyInstall === true,
    priorDuty: tri(p.emergencyPriorDuty),
    newBuilding: p.newBuildingFirstUse !== null,
    firstUse: p.newBuildingFirstUse ?? '',
    applicationBefore: tri(p.buildingApplicationBefore20260513),
    noticeOn: p.halfSplitNoticeOn ?? '',
  }
}

export function halfSplitBody(f: HalfSplitForm): { body: HalfSplitBody } | { error: string } {
  if (f.installedOn === '') {
    return { body: { gmodg43InstalledOn: null, emergencyInstall: null, emergencyPriorDuty: null, newBuildingFirstUse: null, buildingApplicationBefore20260513: null, halfSplitNoticeOn: null } }
  }
  if (f.newBuilding && f.firstUse === '') return { error: 'Bitte geben Sie den Tag an, an dem das neue Gebäude erstmals genutzt wurde.' }
  return {
    body: {
      gmodg43InstalledOn: f.installedOn,
      emergencyInstall: f.emergency,
      emergencyPriorDuty: f.emergency ? fromTri(f.priorDuty) : null,
      newBuildingFirstUse: f.newBuilding ? f.firstUse : null,
      buildingApplicationBefore20260513: f.newBuilding ? fromTri(f.applicationBefore) : null,
      halfSplitNoticeOn: f.noticeOn === '' ? null : f.noticeOn,
    },
  }
}
```
